# Release

What a release needs beyond the code.

- `checklist.md`: what must be true before a listing or launch, before traffic moves, and after. Tick items with the date; `n/a` with a reason is a valid answer.
- `privacy-policy.md`: the full policy, its "things the policy says that the owner has to make true" list, and its `TBD: owner to confirm` items, until it is published.
- `data-inventory.md`: every piece of personal data, where it is stored, why, for how long, and who processes it. Source for the store privacy answers and the policy.
- Store listing copy, screenshot plans, review notes, and the hand-off prompt for a submission, all following `../product/voice.md`.

Release lessons from earlier projects are folded into the checklist; add this project's own to `../lessons.md`.
