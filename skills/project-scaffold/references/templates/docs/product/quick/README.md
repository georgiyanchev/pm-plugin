# Quick-track records

Small features and enhancements that skip discovery and the brief. `feature-quick` (the `pm` plugin) writes one dated file per feature here, `<YYYY-MM-DD>-<slug>.md`, and appends its product check, assessment, plan, and shipped notes to the same file.

Quick records are out of band: no row in `../INDEX.md`. A feature that turns out to be size M or L is escalated to `feature-discovery` and gets its own folder under `..`.
