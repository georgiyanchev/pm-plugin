# Product

The owner's folder for product material. The `pm` plugin's skills read and write here; nothing in it is code.

| What | Where | Written by |
|---|---|---|
| Feature index: one row per feature, status, next step, parked ideas | `INDEX.md` | `feature-pipeline`, `feature-discovery` |
| One folder per feature: `00-intake.md`, `01-brief.md`, `02-prd.md`, `03-design/`, `04-plan.md`, `05-retro.md`, `audits/` | `<slug>/` | the pipeline skills |
| Small features that skip the brief, one dated record each | `quick/` | `feature-quick` |
| Product-scope capability gap audits, dated | `audits/` | `capability-gap-audit` |
| Living capability inventory | `capabilities.md` | `capability-gap-audit` |
| How the product sounds | `voice.md` | owner, agents propose |
| Who it is for | `target-audience.md` | owner, agents propose |

Slugs are kebab-case. `audits` and `quick` are reserved folder names. Gate decisions are recorded only when the owner states them.
