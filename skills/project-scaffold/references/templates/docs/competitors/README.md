# Competitor research

Competitor facts for TBD: product name. A competitor research run, a capability gap audit and a discovery run's competitor export (`pm` plugin) append their facts here; feature discovery and later runs read this folder before any web search.

**Append only.** Each competitor has one `<competitor-id>.md` file, and every run adds a dated `## Update YYYY-MM-DD (<source>)` section to it. The capability matrix is `capabilities-<YYYY-MM-DD>.md`. Other notes here stay and are read. Prior prose is never edited; a contradiction is recorded as a new fact marked `supersedes <file> (<date>)`. Analysis and ranking live in `docs/product/**/audits/`, not here. Working files (raw crawls, scripts) go in a `research/` subfolder or the session scratchpad.
