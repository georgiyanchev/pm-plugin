# Design concepts

Concept rounds, one folder per screen or surface: `<screen>-concepts/` holding the HTML or image concepts of the current round and a `README.md` with the chosen direction. When a round is replaced, move it to `<screen>-concepts/_previous-round/` (numbered when there are several); never delete a round the owner has seen.

Borrowed assets (fonts, photos, icons) carry a `CREDITS.md` in the folder that uses them: source, licence, and whether the asset may ship.

`feature-design` (the `pm` plugin) writes here during a feature's design step; the final rules go into `../DESIGN.md`.
