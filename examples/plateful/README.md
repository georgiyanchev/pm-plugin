# Plateful: example outputs of the `pm` plugin

Plateful is a synthetic product made up for these examples: a weekly meal planner for two people who cook at home, built as an Expo mobile app by a solo, part-time founder. It is not a real product, and no real person, company or client appears in these files. Each file below was produced by one `pm` skill, shortened for reading.
